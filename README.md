Palm Reef: Street Heat — a top-down open-world crime game that runs in the browser from
static files. Explore the six districts of Palm Reef on foot and by car: steal rides,
run Marla's three jobs, fight, and outrun a five-star wanted level with police who ram
and box you in. Traffic, pedestrians, a minimap HUD, a save/continue run, and a pocket
synth for sound — no build step, no network, all original.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD/arrows move, Shift runs, E enters or steals a
car, F/Space punches, P pauses.
